# CADe SIMU Control Circuits

This repository contains electrical control circuit projects designed and simulated using CADe SIMU.

## Project Topics

- Start/Stop Control Circuits
- Self-Holding (Latching) Circuits
- Motor Control Circuits
- Timer Relay Circuits
- Contactor and Relay Logic
- Industrial Automation Applications

## Software

- CADe SIMU

## Purpose

To develop practical skills in electrical control systems, relay logic, motor control, and industrial automation through circuit design and simulation.
